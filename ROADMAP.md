# Open-source roadmap

Awesomic is an AI workspace where your team, any AI agent and experts work in one project on a
cloud computer that's always on. We plan to open-source the code. This page shows where we are.

Dates marked **TBD** aren't fixed yet. We'll update this page and the pinned issue when they are.

| Stage | When | What happens |
| --- | --- | --- |
| 1. Public repo | October 2026 (now) | This repo opens for bug reports, feature requests, docs and download links. Current release: **Awesomic Supernova**. |
| 2. Security review | October – November 2026 | We review and clean up the code before it goes public: secrets, auth, permissions, dependencies. |
| 3. Code release | November 2026 (exact date TBD) | The source code is published in this repository. License announced. Code pull requests open. |
| 4. After release | TBD | Contributor guide, `good first issue` labels, self-hosting notes, translations. |

## What stays the same after the code drop

- This repository: same URL, same issues, same stars.
- Downloads stay on the [download page](https://studio.awesomic.com/download).
- Bug reports and feature requests keep using the same templates.

## What we haven't decided yet

- the license
- which parts are published first, if not all at once
- whether self-hosting is supported at launch

Follow along: watch the repo, or subscribe to the pinned issue
"Open-source roadmap: November 2026".
