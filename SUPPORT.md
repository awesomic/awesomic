# Need help?

> **TL;DR** Bugs and ideas go to **GitHub issues**. Security goes to **SECURITY.md**. Account help is at **awesomic.com**.

## Steps

1. Check the [docs](docs/README.md), especially [Generation failed or is stuck](docs/guides/generation-failed-or-stuck.md).
2. Still stuck? Pick the right place below.

## Where to go

| You want to… | Go here |
|---|---|
| 🐞 Report a bug | [Open a bug report](https://github.com/awesomic/awesomic/issues/new?template=bug_report.yml) — add a screenshot if you can |
| 💡 Suggest a feature | [Open a feature request](https://github.com/awesomic/awesomic/issues/new?template=feature_request.yml) |
| 🔒 Report a security issue | [SECURITY.md](SECURITY.md) — please don't post it publicly |
| 🙋 Get help with your account | [awesomic.com](https://awesomic.com) |
| 💼 Work at Awesomic | [awesomic.com/hiring](https://www.awesomic.com/hiring) |
