# Media kit

> **TL;DR** Writing or talking about Awesomic? Use these names, facts, logos and screenshots.

## Steps

1. Spell the name right: **Awesomic**.
2. Use the **one-liner** below.
3. Use the official **logo** files. Do not change them.
4. Pick **screenshots** from the table.
5. Check the **facts** before you publish.

## Name

- Write **Awesomic**. One word, capital A.
- The current release is **Awesomic Supernova**.

## One-liner

> Awesomic is an AI workspace where your team, any AI agent and experts work in one project, on a cloud computer that's always on.

- Show third-party logos in their **official colors**.
