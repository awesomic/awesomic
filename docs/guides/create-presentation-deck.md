# Create a presentation deck

> **TL;DR** Tell the agent the **audience**, **purpose**, **structure** and **look**. Then review the deck and ask for changes.

## Steps

1. Describe the **audience**, **purpose**, **length** and **source material**.
2. Name the **key message**, required **sections** and **visual direction**.
3. Press **Send**. Follow progress in the task chat.
4. Review the **structure**, **slide content** and **exports**.
5. Ask for changes by naming the **slide** or **story beat**.

## What you get

- A deck you can review, plus the project files that finished.

## If something goes wrong

- A slide or export failed? **Keep the task.**
- Note the **slide**, the expected content and the **error**. Then retry.

## Good to know

- Final **length** and **export formats** depend on the request.
- Check **facts** and **sources** before you present.
