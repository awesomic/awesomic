# Start your first generation

> **TL;DR** Write a brief, check the **project** and **model**, press **Send**. The task chat opens and shows progress.

## Steps

1. Open **New task**. Write your brief in the prompt box.
2. Check the **editable project** and the **model** you want.
3. Wait for **uploads, imports and voice input** to finish.
4. Press **Send**. This creates the task and opens the **task chat**.
5. Watch the status: **queued**, **starting**, **running**.
6. Review files or previews. Reply with **follow-ups**.

## What you get

- The task chat shows **progress, messages, errors** and outputs as they arrive.
- A good start does **not** promise HTML or a fixed set of files.

## If something goes wrong

- Projects still **loading**? Keep writing and wait.
- **No projects**? Loading is done, but you have no editable project.
- **Send** unavailable? Check: prompt not empty, project selected, no send already running, uploads done with no errors.
- **Billing error** after Send? You need an active plan, personal credits or team budget.
- Chat says **queued** or **running**? Just wait.
- Chat shows an **error**? Fix the input it names, then try again.
- Loading ends with **no messages**? Go back to **New task** and start again.

## Good to know

- A **shared prompt link** keeps its text through sign-in. It does **not** start the task.
- Only **Send** starts a task.
