# Create a web app

> **TL;DR** Describe the **user**, the **workflow** and the **screens**. The agent builds a working app you can preview.

## Steps

1. Name the **user**, their **main job** and what **success** looks like.
2. List the **screens**, **data limits**, and **loading, empty and error states**.
3. Attach existing **code** or **references** if they are the source of truth.
4. Press **Send**. Review the running **preview** and the **files**.
5. Report bugs as: **action**, **what happened**, **what you expected**.

## What you get

- A project with a **preview** and **files**, with your workflow built.

## If the preview fails

- Keep the **build error** and the **route** it hit.
- Ask the task to fix the **root cause**, rerun checks and show the fixed workflow.

## Good to know

- External services, credentials and production actions keep their **normal approvals**.
- A preview that **looks** right does not prove every workflow **works**.
