# Generation failed or is stuck

> **TL;DR** Read the **status** and **error** first. Then fix the cause and continue in the **same task**.

## Steps

1. Read the **status**.
2. Confirm the **task**, **editable project**, finished inputs and **account access**.
3. Read the visible **error**. Do not copy private content.
4. Check if **files already exist** before retrying.
5. Fix the named requirement. **Continue in the same task.**
6. Retry **only** for temporary failures or a shown retry action.

## What the status means

- **Queued** or **running**: still working.
- **Temporary connection** notice: not a failure by itself.
- **Blocked**: check input, project, permission or usage access.
- **Failed turn**: shows a stable error or a retry action.

## Still stuck?

- Share the **task ID**, safe **error text** and **time** of the attempt.
- Never share **credentials, private files** or customer data.
- Report it: [open a bug report](https://github.com/awesomic/awesomic/issues/new?template=bug_report.yml).
