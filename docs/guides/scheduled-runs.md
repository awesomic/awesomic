# Scheduled runs

> **TL;DR** Run a supported task **later** or **on repeat**. Review every run.

## Steps

1. Pick an eligible **task**. Open its **schedule controls**.
2. Set the **time** and **recurrence**.
3. Check **account, project and tool** requirements.
4. **Save**. Confirm the schedule is **active**.
5. Review **run history**. Pause or remove it when done.

## What you get

- Each run shows up as a **separate execution** at the set time.

## If a run fails

- Open its **task result**.
- Fix the input, access or tool issue **before the next run**.

## Good to know

- Schedules follow the **normal** account, project, permission and app rules.
- Double-check **time settings** before repeating.
