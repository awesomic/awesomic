# Skills

> **TL;DR** **Skills** are focused instructions that help the agent with recurring work. Awesomic picks the right ones for each task.

![Skills](../../.github/assets/screenshots/skills.jpg)

## Steps

1. Send your request as usual. Awesomic picks **relevant skills**.
2. For a repeatable team method, add a **project skill** in supported project settings.
3. Review the result. Your **request and files** stay the source of truth.

## How it works

- **Built-in skills** help with design, code, documents and media.
- **Project skills** keep a team method without long checklists in every prompt.

## If something goes wrong

- A skill **conflicts** with your goal? Say so in the task, with the behaviour you expect.
- Fix an **invalid project skill** before you reuse it.

## Good to know

- Not every task needs a skill.
- A skill does **not** grant permissions, connect accounts or override safety rules.
