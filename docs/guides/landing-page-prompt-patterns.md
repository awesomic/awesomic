# Landing-page prompt patterns

> **TL;DR** Strong prompts name the **offer**, **audience**, **proof**, **one goal**, **brand** and **sections**.

## Steps

1. Name the **offer** and **audience**.
2. Pick **one primary action**.
3. Add **proof** and common **objections**.
4. List required **sections**.
5. Add **brand direction** and **responsive** behaviour.
6. Use **approved claims** only.
7. Has a form? Ask for **loading, success and error** states.

## Example

> Create a landing page for a team planning service aimed at design leads. The primary action is booking a consultation. Use the approved customer quotes, address delivery-time concerns, and include overview, process, proof, pricing approach, and final action sections. Follow the attached brand guide and keep the mobile action visible without covering content.

## If something goes wrong

- Result is **generic**? Add specific **proof** and **objections**.
- Copy **invents a claim**? Replace it with approved source. Ask for a fact review.

## Good to know

- The **Landing page** suggestion only fills the prompt box.
- It does **not** send, promise HTML or publish.
