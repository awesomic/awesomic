# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

We want this to be a welcoming place for everyone, regardless of background or experience.

**Do:**

- be respectful and patient, even when you disagree
- give and take feedback in good faith
- focus on what's best for the community and the people using Awesomic

**Don't:**

- harass, insult or demean anyone
- use sexual language or imagery, or make unwelcome advances
- publish someone's private information without their permission
- troll or derail conversations on purpose

## Scope

This applies in this repository (issues, pull requests, discussions) and anywhere you represent the
project publicly.
