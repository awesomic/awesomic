# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Email **security@awesomic.com** <!-- TODO: confirm address --> with:

- what you found and where (web, desktop, mobile, API, a published site)
- steps to reproduce, or a proof of concept
- the impact you think it has
- your name or handle, if you'd like credit

We'll confirm we got your report within 3 business days <!-- TODO: confirm SLA --> and keep you
updated while we work on a fix. Please give us reasonable time to fix the issue before sharing it
publicly.

Please don't access other people's data, run destructive tests, or degrade the service for others
while testing.

## About the source code

The Awesomic source code isn't public yet. Before we publish it (planned for November 2026), it goes
through a dedicated security review. When the code is released, this policy will be updated with
supported versions and details on how we handle reports against the open-source code.
