# Contributing to Awesomic

> **TL;DR** **Issues** are welcome. **Pull requests** close automatically until November 2026.

Thanks for being here. 💛

## Steps

1. 🔍 Search open issues first.
2. 🐞 Found a bug? [Open a bug report](https://github.com/awesomic/awesomic/issues/new?template=bug_report.yml).
3. 💡 Got an idea? [Open a feature request](https://github.com/awesomic/awesomic/issues/new?template=feature_request.yml).
4. 💼 Want to build Awesomic with us? [We're hiring](https://www.awesomic.com/hiring).

---

## 🐞 Issues — welcome

Found a bug? Open an issue.

**A great bug report has:**

1. **What you did** — the steps.
2. **What happened** — and what you expected.
3. **A screenshot** — or a short screen recording. This helps the most.
4. **Where** — Mac, Windows, Linux, iOS, Android or Web.

👉 [Open a bug report](https://github.com/awesomic/awesomic/issues/new?template=bug_report.yml)

**Got an idea?** [Open a feature request](https://github.com/awesomic/awesomic/issues/new?template=feature_request.yml).
Tell us the problem first, then the fix you'd like.

Before you post:

- 🔍 Search open issues. Add a 👍 instead of a duplicate.
- 🚫 Never share passwords, API keys or private project links.
- 🔒 Security problem? Use [SECURITY.md](SECURITY.md), not issues.

---

## 🔀 Pull requests — not yet

- The source code isn't public yet.
- It lands here in **November 2026**, after a final security review.

- Until then, **pull requests close automatically.**
- You can open one to show an idea. We read it, but can't merge it.
